Algorithm 2 Thompson Sampling for Candidate Recommendation
1: Input: Job j, candidate pool C, prior parameters α0, β0
2: Output: Ranked list of candidates
3:
4: // Group candidates into ”arms” (e.g., by skill cluster)
5: A ←cluster candidates(C, method = kmeans, k = 10)
6:
7: for each arm a ∈A do
8:

9:

10:
11:

12:

13: end for
14:
15: // Select arm with highest sampled probability
16: a∗←arg maxa θa
17:
18: // Rank candidates within selected arm using GLMix
19: candidates ←A[a∗]
20: scores ←[GLMix score(c, j) for c ∈candidates]
21: return rank by score(candidates, scores)
 Exploration: Occasionally try candidates from uncertain clusters
 Balance: Thompson Sampling naturally balances via uncertainty in Beta distribution
Cold Start Strategy:
1. New company: Use global priors α0 = 1, β0 = 1 (uniform prior)
